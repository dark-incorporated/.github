# Seed ideas

The owner's own ideas for the Dark Factory and the family, written in the owner's words.
This file is the owner's: an agent never adds a row, never edits the **Idea** column, and never deletes a row.
`/dark-inc-feature-research` may set **Status** to `researched` and add a link under **Research**; `/dark-inc-feature-backlog` may set **Status** to `adopted` or `dropped` and add issue links under **Issues**.
To research a seed, run `/dark-inc-feature-research S-<nnn>`.

| ID | Date | Idea | Status | Research | Issues |
|---|---|---|---|---|---|

**Status** is one of `open` (new, not yet researched), `researched` (a research document covers it), `adopted` (issues were filed from it) or `dropped` (researched and not taken up).
IDs run `S-001`, `S-002`, … in order, and the owner assigns them.
